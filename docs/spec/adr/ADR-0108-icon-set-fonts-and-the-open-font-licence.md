# ADR-0108 — One Icon Set, Lucide, And Two Self-Hosted Fonts, Inter And JetBrains Mono, Under The SIL Open Font Licence

- **Status:** Accepted
- **Decision:** AudioGubbins draws every icon with Lucide, through `lucide-react`, and sets every word of its interface in two variable fonts it ships itself: Inter for text and JetBrains Mono for every time, level and frequency readout, through the `@fontsource-variable/inter` and `@fontsource-variable/jetbrains-mono` packages. Both are reached only through `@audiogubbins/design-system`: its `Icon` component names icons by AudioGubbins' own vocabulary and maps each to a Lucide glyph, and its stylesheet declares the font faces. No feature imports an icon package or a font file (`REQ-UX-221`, `ADR-0009`).
  - **Lucide** is one stroke-drawn set on a 24-unit grid with round caps and joins at one stroke weight, which the language draws at 1.75 units. It is licensed under ISC, and the icons it derives from Feather under MIT; the licence file it ships states both, both are on the allow-list, and its manifest's `ISC` names the licence of the package. A glyph Lucide lacks, such as a fade or a knob, is drawn by AudioGubbins to the same grid, stroke and caps, inside the design system, and is ISC like the rest of the set it joins.
  - **Inter and JetBrains Mono** are licensed under the SIL Open Font License 1.1, with no Reserved Font Name. OFL-1.1 joins the allow-list of `tools/sync-third-party-notices.mjs` by this decision. Its conditions: the fonts may be used, embedded, bundled and redistributed with any software, the copyright notice and the licence travel with them, which the third-party notices do, and the fonts may not be sold on their own. Its copyleft reaches only the font software: a modified font must stay under OFL-1.1 and, where a font names a Reserved Font Name, give up that name. Neither font is modified, subsetted beyond the per-script files the packages ship, or sold, so no condition reaches AudioGubbins' own code or licence.
  - **Self-hosted.** The font files are bundled with the application and precached for offline use (`REQ-PWA-031`); none is fetched from a third-party host. Each face falls back to a stated stack of the same metrics class (`system-ui` for Inter, `ui-monospace` for JetBrains Mono), so a face that fails to load changes no layout beyond the type scale's tolerance.
- **Drivers:** `REQ-UX-221` (one icon set under a licence the repository accepts; a type scale with tabular figures for every readout), `REQ-REPO-033` and `REQ-REPO-142` (a dependency's licence reviewed, its popularity and maintenance vetted, dependencies kept few), `REQ-PWA-031`, and the product owner's direction recorded in `CHG-0002`. Remix Icon was refused: its manifest states Apache-2.0 and the licence it ships is a custom one. A system font stack was refused: it draws differently on each operating system, so neither the language's metrics nor a screenshot baseline would hold, and Windows' Segoe UI has no tabular figures in its default features.
- **Constraints:** the icon set and the fonts are each one dependency of `@audiogubbins/design-system`, pinned. A second icon set, an icon drawn ad hoc in a component, and a font fetched from another host are refused (`REQ-UX-221`, Phase 16 forbidden shortcuts). OFL-1.1 is allowed for font software only: the notices tool names the font packages it accepts under it and refuses any other package under it, and a font that names a Reserved Font Name needs a decision of its own before it is used modified.
- **Change record:** affected requirements `REQ-UX-221`, `REQ-REPO-033`, `REQ-REPO-142`, `REQ-PWA-031`; affected phase 16. Compatibility impact: none to the project, its storage or the workspace format. Public API: `Icon` and the icon vocabulary of `@audiogubbins/design-system`. Godot interchange and runtime: none. PWA and browser: the font files join the precached build. Verification: the notices tool lists the three packages with their shipped licence texts; an architecture rule refuses an import of `lucide-react` or a font package outside the design system; a browser test holds the layout when the fonts fail to load.
- **Related requirements:** `REQ-UX-221`, `REQ-UX-155`, `REQ-REPO-033`, `REQ-REPO-142`, `REQ-PWA-031`.
