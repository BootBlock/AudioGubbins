# Architecture Decision Records

ADRs capture significant implementation choices already decided by the specification or later approved during implementation.

## Rules

- Status values: `Proposed`, `Accepted`, `Superseded`, `Rejected`.
- An ADR cannot reduce a normative requirement.
- If an ADR conflicts with a requirement, the requirement wins until an approved specification change updates it.
- Later ADRs may supersede earlier ADRs explicitly; never silently rewrite history.
