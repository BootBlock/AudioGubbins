# Phase 08 — Spectral Editing — Review Record

## The owner's decision

On 2026-10-07 the owner decided that in-depth reviews, audits and their fix
rounds happen once, after the whole specification is implemented, and not
during any phase; a lens a phase packet requires is to be recorded as
deferred to the post-implementation review instead. Phase 08 therefore ran no
independent review lens. In their place a separate agent, which had not built
the phase, made a read-only scope check; the build and the integration
found thirteen more defects.

On 2026-10-10 the owner further decided that the fix round's slices run the
tests of what they changed, the type checks and lint, and that one full
`pnpm run verify:commit` runs over the integrated branch, recorded in the
evidence (`reviews/phase-08-evidence.md`).

Severity follows `contracts/review-gates.md`. `BLOCKER`, `CRITICAL` and `HIGH`
prevent `PASS`. `MEDIUM` must be fixed or explicitly accepted with
justification and tracking. `LOW` and `NOTE` may remain if tracked.

**Status** `CONFIRMED` means established by reading the code against the
packet, or, for a finding the build made, reproduced by a failing test or
browser run. No finding was rejected. Findings are numbered for this phase
alone: the scope check's from F-01, the build's from B-01.

## The scope check

every In Scope item, acceptance criterion, architectural invariant, failure
and recovery behaviour, forbidden shortcut, inherited debt and required public
contract of the packet, and against `ADR-0080` to `ADR-0082`. It edited
nothing. It found one defect that prevents `PASS`, eight items carried out in
part or untested, and four wordings or facts with two homes. Each was
confirmed by reading the code again; the race of F-09 was confirmed by a test
that failed against the code it found.
